# 大模型防幻觉机制

**相关笔记**: [[大模型人格化]], [[大模型持续学习]]

## 概念定义
**大模型防幻觉机制（Anti-Hallucination Mechanisms）** 是指在 Prompt Engineering 或大模型应用架构中，通过一系列显式的逻辑约束，最大限度地减少大模型“一本正经地胡说八道”（事实错误或捏造内容）的工程手段。

## 核心落地策略

### 1. 基础约束策略
*   **显式授权“不知道”**：明确在 Prompt 中赋予大模型承认“信息不足”或“不确定”的权限，打破其默认的“必须给出答案”的对齐倾向。
*   **强制原文提取（Grounding）**：对于长文本分析，要求模型先**逐字提取**相关引用（Direct Quotes），再基于提取的引用进行总结。切断其从参数记忆中凭空捏造信息的路径。
*   **引文验证（Citation Verification）**：要求模型在生成最终主张后，反向回溯并附上支持该主张的文档来源。若找不到依据，强制撤回或打上空括号 `[]` 标记。

### 2. 高阶验证技术
*   **思维链验证（Chain-of-Thought Verification）**：强迫模型在输出最终答案前，显式写出推理过程（`<think>` 或步骤说明），这能极大暴露底层逻辑漏洞。
*   **N 次最佳验证（Self-Consistency / N-best Validation）**：用相同的 Prompt 多次请求模型，对比输出结果的方差。若结果不一致，则说明触发了知识盲区或产生了幻觉。
*   **外部知识限制（External Knowledge Limitation）**：通过强硬的系统指令（如 `仅使用提供的文档中的信息，绝对禁止使用你的预训练知识`）切断内生幻觉。
