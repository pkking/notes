# Local-First Architecture (本地优先架构)

本地优先架构（Local-First Architecture）是一种软件架构模式，其核心原则是：**客户端应用（如浏览器、移动端）将本地存储（如 IndexedDB、SQLite、本地文件系统）作为首要的数据读写源，而远程服务器仅仅作为后台的同步节点。**

## 核心特点
1. **零延迟响应**：用户的读写操作直接在本地数据库完成，UI 响应极快，无需等待网络请求（消除 Loading 状态）。
2. **离线可用性**：即使在没有网络连接的情况下，应用也能提供完整的读写功能。
3. **后台增量同步**：当网络恢复时，应用通过增量同步机制（如 CRDT、WebSocket 事件流）将本地状态与云端或其他设备进行合并和冲突解决。
4. **边缘计算友好**：非常适合结合 CDN 静态托管和边缘计算，极大降低中心化数据库的压力。

## 在 GitHub Actions 监控中的应用
在构建需要规避严格 API 速率限制（Rate Limits）且要求极高页面性能的监控大屏时，可以利用 Local-First 理念：后端或定时任务仅生成高度压缩的增量 JSON 快照存放在 CDN，前端拉取后缓存在本地 IndexedDB 中。用户的后续查询、聚合、历史统计全部利用本地客户端算力完成，实现近乎零延迟的数据大屏体验，彻底摆脱频繁请求云端带来的性能瓶颈。
